# 개가의 호포 한글화 번역 규칙

## 파일 형식
- `translation/ko/*.tsv` : `id \t 원문 \t 번역 \t [용량]` (UTF-8, 탭 구분, 줄바꿈은 `\n`으로 표기)
- 3번째 칸(번역)만 채운다. 원문 칸은 절대 수정하지 않는다.
- 기계 번역 금지. 직접 자연스러운 한국어로 번역.

## 문자
- 사용 가능한 한글: KS X 1001 완성형 2,350자(대부분의 일반 글자). 드문 글자(예: 똠, 뷁, 쌰 등) 피하기.
- 숫자·영문·공백은 반각 ASCII 사용 가능(반각 폭으로 출력). 문장 내 띄어쓰기는 반각 공백.
- 문장부호: `. , ! ? ~ ( ) : / -` 반각 사용 가능. 「」『』・…은 원문처럼 써도 됨. `・・・` → `...` 대신 원문처럼 `・・・` 유지 가능.
- 제어코드 `$03`, `$24$25$26` 등 `$숫자`는 반드시 그대로 유지(버튼 아이콘·변수). 위치는 한국어 어순에 맞게 옮겨도 됨.
- 전각 숫자(１２３)는 반각(123)으로 바꿔도 된다.

## 줄바꿈 (중요)
- 시나리오(event_*, brief_*, tutmsg의 튜토리얼 문단): 게임이 자동 줄바꿈하므로 문장 중간의 줄바꿈은 **없앤다**.
  원문의 빈 줄(문단 구분, `\n\n`)과 문단 끝 `\n`, 화자 이름 줄은 유지한다.
- 대사 형식: 화자 이름 줄 다음 `「…」` 한 덩어리로 쓴다(내부 줄바꿈·전각 들여쓰기 없이). 예:
  `男\n「그건 그렇고 사람 많네.」\n` → `남자\n「그건 그렇고 사람이 많네. 딱히 무슨 일이 있는 것도 아닌데 다들 들떠 가지고.」\n`
- 원문 끝에 `\n`이 있으면 번역 끝에도 `\n`.
- 짧은 확인창 메시지(msg 계열, 한 줄 12~20자짜리)는 원문처럼 직접 `\n`으로 줄을 나누고, 각 줄은 원문 최대 줄 길이(전각 글자 수) 이내, 줄 수는 원문 이하로.
- 병기 설명(msg, `特殊能力なし` 등 한 줄짜리)은 한 줄로.

## 고정칸(fixed_*.tsv)
- 4번째 칸 = 최대 바이트 수. 한글 1자=2바이트, 반각 1자=1바이트. 반드시 이내로.
- 원문이 깨진 바이너리(예: `P畛`, `鏖%`)처럼 의미 없는 것은 번역 칸을 비워 둔다.
- 개발용 주석(`ここが福岡県。何がなんでも…`)도 그냥 번역해도 무방.
- 병기 이름: 영문 기종명(Ｆ－１５ 등)은 그대로 두거나 반각으로(F-15). 가타카나 이름은 한국에서 통용되는 표기(레오파르트2, 치프틴, 챌린저 …).

## 문체
- 브리핑·해설: 평서체 "~다", 튜토리얼 안내: "~합니다/하세요".
- 대사는 인물에 맞게 구어체.
- 일본 지명은 국립국어원 일본어 표기법(도쿄, 오사카, 후쿠오카, 기타큐슈, 가고시마 …). 현은 "○○현", 도/부는 "도쿄도", "오사카부", "교토부".
