# 기술 문서

대상: PS2 「凱歌の号砲 エアランドフォース」 일본판 (SLPM-65260, KOEI / Cyc), DVD 이미지 1장(4,697,489,408 바이트).

## 파일 구성
- `GAIKA.BIN` — 실행 파일(메뉴·부대·병기 이름 등 고정 길이 문자열 포함)
- `DATA/ARC.INF` + `DATA/*.ARC` — 묶음 파일. INF에 묶음별 항목 표(16바이트: 4×u16, 크기, 오프셋)가 있고 ARC는 2048바이트 정렬로 이어 붙인 구조
  - `SCN.ARC` — 시나리오·브리핑·튜토리얼(NUL 구분 문자열 목록, Shift-JIS)
  - `MSG.ARC` — 확인창·도움말 메시지(NUL 구분 문자열 목록)
  - `SYS.ARC` — 9/11/14번 고정칸 문자열, 13번 글꼴, 나머지 TIM2 그림
  - `MAPDATA.ARC` — 지명 고정칸 문자열
- `MOV/OP.PSS`, `MOV/ED.PSS` — 오프닝·엔딩 동영상(MPEG-2 PS), 일본어 자막이 영상에 그려져 있음

## 문자·글꼴
- 게임 글꼴은 22×22 4bpp(글자당 242바이트), Shift-JIS 2바이트 코드로 색인합니다.
- 쓰이지 않는 한자 칸에 KS X 1001 완성형 한글 2,350자를 나눔스퀘어 네오 ExtraBold로 그려 넣고, 한글 → 그 칸의 Shift-JIS 코드로 변환하는 표(`tools/kfont.py`)로 텍스트를 인코딩합니다.

## 텍스트 삽입 (`tools/build.py`)
- 문자열 목록(SCN/MSG): 번역을 인코딩해 다시 묶음. 길이가 바뀌므로 ARC를 재구성하고 ARC.INF의 크기·오프셋을 고칩니다.
- 브리핑 창 폭에 맞춰 직접 줄바꿈(SCN0~12: 54, 13~25: 50 반각 폭), 브리핑은 13줄 제한, 대사창은 3줄 단위로 문장·문단이 페이지 중간에 갈리지 않도록 빈 줄을 채웁니다.
- 고정칸 문자열(SYS/MAPDATA/GAIKA.BIN): 원래 칸 크기 이내로만 덮어씁니다.
- `tools/patch_code.py` — 실행 파일 안 문자열 포인터·폭 관련 수정.

## ISO 재구성 (`tools/isopatch.py`)
- 커진 파일(ARC.INF, *.ARC, GAIKA.BIN)은 `PADDING/DUMMY00` 영역(LBA 353~)으로 옮기고 디렉터리 레코드의 LBA·크기를 고칩니다. ISO 전체 크기는 원본과 같습니다.
- 재빌드 때는 먼저 레코드를 원본 값으로 되돌린 뒤 배치해 영역이 겹치지 않게 합니다.

## 그림 글자 (`tools/images.py`, `tools/img_specs.py`, `tools/retext.py`)
- TIM2 8bpp 그림 60여 종(타이틀 부제·읽는 법, 메뉴 라벨, 부대 명령, 튜토리얼 화면 등)의 일본어를 지우고(채우기/인페인트/행 채우기) 한글을 그린 뒤 원래 팔레트로 양자화합니다. 파일 크기는 그대로입니다.
- 글꼴: 서울한강체(EB/B/M), 나눔스퀘어 네오, 아주 작은 글자만 갈무리11.

## 동영상 자막 (`tools/movsub.py`, `tools/pss.py`, `tools/movtext.py`)
- PSS에서 비디오 ES를 꺼내 자막이 있는 GOP만 디코드 → 일본어 자막 영역을 지우고(OP: 인페인트, ED: 흐림 채우기) 원래 스크롤 속도·투명도에 맞춰 한글 자막을 그림 → ffmpeg로 같은 GOP 구조(원래 키프레임 위치)로 재인코딩 → 원래 ES에 GOP 단위로 이어 붙입니다.
- 팩·PES 구조와 PTS는 그대로 두고 비디오 페이로드만 교체하며, 남는 비디오 PES는 패딩 패킷(0xBE)으로 바꿔 파일 크기를 유지합니다.
